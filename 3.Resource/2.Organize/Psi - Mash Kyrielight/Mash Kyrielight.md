**Ini mulai menunjukkan sesuatu yang penting:** perusahaan pada layer bawah **tidak hilang ketika layer baru muncul**. Mereka menjadi **infrastruktur bagi layer berikutnya**.

Contoh paling jelas:

> **Siemens/GE → listrik → electronics → computing → semiconductor → AI**

atau:

> **Heavy Industry → Mass Production → WWII → Aerospace → Electronics → Computing → AI**

Jadi kalau tujuan akhirnya adalah membuat **model sejarah emergence industri**, saya justru akan menjadikan **“Fase Layer” sebagai dimensi utama**, lalu perusahaan sebagai **node** di dalam setiap layer. Itu memungkinkan kita nanti membuat **network/graph industri**, bukan sekadar timeline perusahaan.
